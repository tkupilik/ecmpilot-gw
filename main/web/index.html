Automatic vehicle refresh

Uses the last reported charging state. A shorter period limits the running countdown without restarting it. Known 12V SOC below the limit pauses automatic refresh; unknown SOC does not block it.

Charge limit

Requires automatic refresh and fresh vehicle data. At the target, the gateway requests delayed charging using the start time stored in the car. Charging can resume at that time.

Automatic deep sleep

After this long without a valid BSI message, the gateway turns off Wi-Fi and sleeps. CAN activity wakes it. Connecting the phone does not keep it awake. Vehicle refreshes restart the inactivity period; if low 12V battery stops refreshes, the inactivity countdown can expire.

Power measurement

Manual CPU/sleep policy. Normal: 160 MHz. DFS: 40–160 MHz. Light sleep: 40–80 MHz with automatic sleep permitted.

Normal/DFS/light policies keep CAN running; the installed TWAI driver prevents actual light sleep. Deep sleep stops Wi-Fi and TWAI, then wakes only on CAN RX activity. Phone/HA cannot reach the sleeping GW. First frames may be lost; active CAN may cause an immediate wake. Automatic entry uses the inactivity setting above. Reboot returns to Normal.

Wi-Fi setup


1–32 letters, digits or hyphens; start and end with a letter or digit. Saved in the gateway and applied when reconnecting. Your router provides the DNS suffix and record (for example ecmpilot-gw.lan); local DNS availability depends on its configuration.

Setup access point

Disabled by default. When enabled, the setup AP starts if there are no saved networks or the gateway stays offline for 30 seconds. When disabled, no setup AP is started; configure Wi-Fi over the serial console if needed.

SSID:


8–63 printable ASCII characters. Leave blank to keep the current password. Changing it restarts the gateway; reconnect the setup AP with the new password.

Known Wi-Fi networks

Up to eight networks, highest priority first. The gateway connects to an available network and retries after a connection loss. Hidden networks are not supported yet.

For a saved network, leave its password blank to keep it. Select “Open network” to remove its password. Saving an empty list enables the setup access point only when AP fallback is allowed.

Home Assistant · MQTT

Share vehicle information with Home Assistant, even when the phone app is closed. Sensors appear automatically through MQTT discovery. Last known values stay visible when the car sleeps; each sensor includes its data age. This connection only reads vehicle information.

Firmware update

Choose ecmpilot_gw.bin from an ESP-IDF build. The gateway writes the inactive OTA slot, validates the image and restarts.

Process signals

INFO CAN supplies SOC, range, outside temperature, odometer and vehicle state. Unknown fields remain invalid until a producer or Force provides them. Set test.enabled to 1 for UDP test controls; incoming targets appear under request.*.

Force overrides the value returned to consumers. Real producer data keeps updating underneath. Forces stay active until Release or reboot. Direct Write and Touch are available only for manual signals.
